# DHCP (Dynamic Host Configuration Protocol)

## 📌 About the Project
DHCP (Dynamic Host Configuration Protocol) is a network protocol that automatically assigns IP addresses and other network configuration details to devices connected to a network.

This project explains the working of DHCP and how it simplifies network configuration by reducing manual work and preventing IP address conflicts.

## 🎯 Objectives
- Understand the basics of DHCP.
- Learn how IP addresses are assigned automatically.
- Understand the DHCP DORA process.
- Learn how DHCP simplifies network management.

## ⚙️ How DHCP Works

DHCP follows four main steps, known as the **DORA process**:

1. **Discover:** The client searches for a DHCP server.
2. **Offer:** The server offers an available IP address.
3. **Request:** The client requests the offered IP address.
4. **Acknowledgment:** The server confirms the IP address assignment.
